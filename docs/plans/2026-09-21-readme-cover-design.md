# README 封面设计说明

## 背景与目标

为 GitHub 仓库制作一张具有独立产品识别度的 README 首屏封面。封面使用真实客户端截图，构图参考用户提供的深色产品展示图，但不复刻其品牌元素。

## 视觉方案

- 画布尺寸：`1600 × 900`。
- 整体方向：深色聚光式产品展示。
- 左侧信息：英文产品名 `Delegate Control for ChatGPT`、中文副标题 `ChatGPT Delegate 桌面控制客户端`。
- 左侧标签：`Windows`、`Tauri`、`MCP`、`Secure Tunnel`。
- 右侧主体：用户提供的真实客户端截图，置于带窗口栏、边框、透视和阴影的产品模型中。
- 品牌色：深墨绿、青色、白色，与客户端现有界面保持一致。
- 不添加虚构功能、下载量、Stars、许可证或官方 OpenAI 标识。

## 文件与 README

- 封面文件：`docs/images/readme-cover.png`
- README 第一项内容使用相对路径展示封面。
- 原始临时截图不纳入仓库，只提交最终封面。

## 验收标准

- 输出尺寸精确为 `1600 × 900`。
- 产品名称及中文副标题清晰可读。
- 客户端截图可辨认且没有拉伸变形。
- GitHub README 顶部首先显示封面，之后才是标题和正文。
- 在桌面与窄屏 README 视图中均可按比例缩放。
